# TrajQABench

Reproducibility materials for a trajectory question-answering benchmark.

## Release status

This repository is being prepared. It is not yet a complete reproduction of the paper's experiments.

The currently prepared local package contains aggregate table and figure reconstruction and reference scoring code with synthetic examples. The evaluated question and split manifests, original per-question responses for the three runs, effective model configurations, and human-audit records still need to be added and verified.

Raw GeoLife trajectories are not redistributed. Data access instructions and the precise reproduction scope will accompany the materials.

## Planned contents

- Reference scoring and split-checking code, with synthetic examples.
- Aggregate data and scripts for reconstructing the paper's tables and numerical figures.
- Environment requirements, data-access instructions, and a reproducibility checklist.
- Original experiment records, when available and verified against the reported results.

This initial repository contains the project description only. Code, data, and experiment records have not yet been uploaded.
